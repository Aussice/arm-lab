# ARM LAB · 机械臂交互实验室

白色三维机械臂工作台：模块装配、关节控制、图像定位、全臂避障、刚体接触与可检查的任务闭环。

https://aussice-arm-lab.aussice.chatgpt.site/

## v8 组装与模型评测

打开导航「组装评测」：插接模块、扣合上盖、换螺丝刀、紧固两颗螺丝并检查结果。无硬件即可手动操作或运行规则基线；配置模型服务后可逐步观察、决策、执行与修正。

提供基础、错位、螺纹卡滞和综合四种场景，固定种子、人工偏移、单步审核、有限预算运行和 JSON 评测记录导出。原始交互实验保留；真实相机和硬件收进高级接入。

这是固定虚拟试件的近似装配约束测试，不是高保真螺纹动力学或任意 CAD 装配。模型可选接收场景图像，同时仍获得仿真状态，不能视作纯视觉评测。完整 PRD、参数与验收见 [docs/ASSEMBLY_MVP.md](docs/ASSEMBLY_MVP.md)。

## 快速体验

打开站点，在「自主任务」中选择六项技能之一，或在「用一句话安排任务」中输入：

> 推红色方块，然后按按钮，最后打开抽屉

每一步完成物理结果检查后才执行下一步。支持暂停、单步、停止、重置。停止释放约束并保留物体当前位置；重置恢复实验台。所有运行状态只在当前页面会话中保留。

## 已实现范围

| 能力 | 交互与结果检查 |
| --- | --- |
| 装配与手动控制 | 五级安装、爆炸视图、底座/肩/肘调节、夹爪开合、装配互锁 |
| 搬运、分拣、堆叠 | 条件夹持约束、释放后重力与碰撞、位置/高度/稳定性检查、最多三次重试 |
| 环境编辑与避障 | 拖动/坐标编辑、无效位置拒绝、动态重规划、旧路线对照、全臂包络检查与有限 A* |
| 方块视觉定位 | 320 × 224 顶视仿真 RGB 图像、三色分割/轮廓检查、遮挡与亮度干预、过期观测停止 |
| 推物 | 不建立夹持约束；夹指碰撞推动约 40 cm，检测接触和落点；偏离时重新选择接触面 |
| 按按钮 | 带回弹的单轴按钮；压下超过 23 mm 且存在物理接触才触发 |
| 开抽屉 | 对位后有条件连接把手；沿导轨牵引，开度至少 350 mm 且稳定才通过 |
| 文字任务 | 本地有限语法，六项技能、最多六步；整句先验证，失败不执行后续步骤 |

按钮与抽屉使用按任务切换的工装，切换时初始化机构；不是同时摆放的永久场景物体。

## v7 外部连接

在页面点击「连接大模型、摄像头与实体设备」，下载本地接入包。完整启动、HTTPS、模型配置、相机标定及设备联调说明见 [bridge/README.md](bridge/README.md)。

- 大模型：兼容 Chat Completions 的服务生成计划，双端验证后由用户确认在仿真执行。没有预填模型或 API 密钥。
- 真相机：浏览器授权采集、选择设备、三色区域检测、四点平面标定；单帧发模型需单独开启。
- 实体设备：myCobot 280 串口适配，默认只读，显式限位、授权心跳、1° 微动、到位检查与停止。其他型号需适配对应驱动。
- 当前尚未在用户的真实账户、摄像头和机械臂上联调，协议测试不能代替实机验收。

## 干预与恢复

- 拖动物体或挡板，观察重新观测和路线变化。
- 对方块施加外部冲量、安排抓取滑落，观察修正。
- 遮住相机目标或降低亮度，目标不可可靠定位时停止。
- 卡住按钮/抽屉，或让把手夹持滑脱，验证失败与有限重试。
- 解锁机构后可继续修正；达到重试上限后需要重新启动。

## 工程边界

主场景是浏览器内的教学仿真；v7 增加了独立的真实相机与实体关节微动接入面板。机械臂采用运动学驱动；动态物体由 Cannon-es 求解。相机由简化几何渲染，只定位已知尺寸的三色方块。按钮和抽屉使用仿真行程读数，碰撞、夹持与结果检查使用物理状态。

全臂检查为离散采样的保守包络，尚未包含精确网格连续碰撞或机器人自碰撞。按钮/抽屉为理想单轴导向与行程限位，抓取为有条件的约束连接。推物修正为有限轴向策略，不能保证任意布局可解。软件渲染兼容模式不具备 WebGL 的完整材质与阴影。

v7 已实现兼容模型服务调用、真实摄像头与 myCobot 280 接入代码，需在用户电脑配置与联调。模型计划只执行仿真技能；实体运动限于带反馈的关节微动，尚未实现真实视觉引导的自主抓取。URDF、关节力矩动力学、自碰撞与手眼标定仍未实现。
